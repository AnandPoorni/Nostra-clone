# NOSTRA – Modern E-Commerce Website 🛍️

**NOSTRA** is a modern, stylish and responsive e-commerce website designed to provide a smooth and attractive online shopping experience. It offers a wide range of fashion, beauty, wellness and lifestyle products through a clean and elegant user interface.

## 🌐 Project Overview

NOSTRA is developed using HTML, CSS and JavaScript. The website features multiple shopping categories, product collections, interactive product cards and individual product details.

The main goal of this project is to create a professional online shopping platform with easy navigation, attractive product displays and user-friendly functionality.

## ✨ Features

- **Modern Homepage:** Attractive hero banner, promotional sections and featured products.
- **New Arrivals:** Explore the latest products and collections.
- **Fashion Collection:** Dresses, tops, jeans, skirts, shirts and more.
- **Tees Collection:** Oversized, graphic, printed, basic and polo T-shirts.
- **Shapewear Collection:** Bodysuits, shaping shorts, leggings and seamless wear.
- **Beauty Collection:** Skincare, makeup, haircare and beauty essentials.
- **Wellness Collection:** Fitness, yoga and self-care products.
- **Kitchen Collection:** Cookware, dinnerware and kitchen accessories.
- **Home Collection:** Home decor, lighting, bedding and storage products.
- **Tech Collection:** Gadgets, headphones and mobile accessories.
- **Product Details:** View product images, descriptions, prices and specifications.
- **Wishlist:** Save favourite products.
- **Search Functionality:** Find products easily.
- **Filter and Sort:** Browse products by category, style and price.
- **Shopping Bag:** View selected shopping items.
- **Responsive Design:** Compatible with desktop, tablet and mobile devices.
